# 무료 대학 AI/ML 강의 노트 학습 가이드

이 가이드는 [과정별 한국어 번역 노트](../lecture/README.md)를 이용해 기초부터 고급 주제까지 학습하는 방법을 설명합니다.

## 학습 순서

1. [시작하기](01_getting_started.md): 선수 지식 점검, 과정 선택, 주간 루틴
2. [핵심 개념 경로](02_core_concepts.md): 공통 ML 개념을 여러 강의에서 교차 학습
3. [고급 학습과 검증](03_advanced.md): 베이지안 추론, 일반화 이론, 재현과 출처 검증
4. [학습 기록 템플릿](templates/course-study-log.md): 강의별 진행 상황과 실험을 기록

## 빠른 시작

- Python 문법·선형대수·확률이 낯설면 KAIST 또는 MIT의 기초 절부터 시작합니다.
- 모델을 구현하면서 배우려면 LMU의 Python/scikit-learn 자료와 Cornell 강의를 결합합니다.
- 이론 중심이라면 Caltech의 일반화 이론을 먼저 보고 Berkeley 또는 Princeton으로 확장합니다.
- 불확실성 모델링이 목적이면 Harvard의 생성 모델·그래피컬 모델 다음 Oxford 베이지안 ML을 학습합니다.

## 사용 원칙

- 이 저장소의 번역은 길잡이입니다. 수식, 과제 조건, 라이선스는 원문을 기준으로 확인합니다.
- 학기별 사이트는 내용이 바뀔 수 있으므로 학습 기록에 접근일과 과정 버전을 적습니다.
- 훈련 성능만 기록하지 말고 검증 분할, 기준선, 실패 사례와 재현 환경을 함께 남깁니다.
