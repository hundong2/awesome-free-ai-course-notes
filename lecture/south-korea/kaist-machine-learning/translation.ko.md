# KAIST Machine Learning iNotes - 학습용 한국어 재구성

원문: [iAI KAIST Machine Learning](https://iailab.kaist.ac.kr/teaching/machine-learning)

확인일: 2026-08-06

원문 상태: 한국어·영어 video와 한국어 중심 학습 자료가 함께 제공됨

## 과정 안내를 쉬운 한국어로

이 페이지는 머신러닝 강의 자료를 학생과 교수자 모두 자유롭게 학습·수업에 활용할 수 있도록 공개합니다. HTML iNote, Keras·PyTorch·Colab 실습, PDF·PowerPoint, problem set과 solution을 주제별로 연결합니다. 페이지는 사용·수정·배포를 허용하며 별도 credit이나 reference를 요구하지 않는다고 안내합니다.

## 확인 가능한 학습 시작점

- installation과 Colab 환경 설정
- Python 기초
- 머신러닝 소개
- linear algebra
- probability와 statistics 기반 개념
- regression·classification과 model evaluation
- neural network 및 framework 실습
- probabilistic machine learning

각 행에서 `iNote → framework 실습 → PDF → problem set → solution` 순으로 학습하면 설명을 읽고 구현한 뒤 이해도를 검증할 수 있습니다.

## 권장 학습법

1. iNote에서 개념과 notation을 정리합니다.
2. Colab에서 example을 그대로 실행합니다.
3. hyperparameter나 data를 하나씩 바꿔 결과 변화를 설명합니다.
4. solution을 보기 전에 problem set을 풉니다.
5. 영어 video를 병행해 영문 용어와 한국어 표현을 연결합니다.

## 주의점

웹 페이지의 `#01`, `#24` 같은 표기는 topic별 자료 번호입니다. 서로 다른 형식의 같은 번호를 한 묶음으로 보면 됩니다. framework API는 자료 작성 이후 달라질 수 있으므로 현재 Keras·PyTorch version을 기록하고 deprecated API를 확인하세요.
