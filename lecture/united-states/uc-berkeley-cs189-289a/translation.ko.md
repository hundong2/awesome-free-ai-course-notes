# UC Berkeley CS189/289A 머신러닝 입문 - 한국어 번역 해설

원문: [CS189/289A](https://eecs189.org/)

확인일: 2026-08-06

확인 학기: Spring 2026

## 과정 소개

수학적 엄밀성과 실제 구현을 결합해 ML 문제 정의부터 data 처리, model 설계, optimization과 평가까지 전체 pipeline을 다룹니다. 현재 root URL은 학기별 site로 갱신될 수 있습니다.

## 원문 syllabus 흐름

- ML 문제 framing과 학습 paradigm 분류
- probability·optimization 수학 복습
- k-means, EM과 PCA를 포함한 비지도학습
- loss, linear regression, MLE와 classification의 연결
- neural network, activation, backpropagation과 PyTorch 구현
- batch normalization, initialization과 regularization
- CNN, RNN, transformer
- LLM, autoencoder, GAN을 포함한 생성 모델

## 선수 지식

multivariable calculus, linear algebra, probability와 discrete mathematics, Python program 작성·debugging 능력이 필요합니다. gradient와 multivariate chain rule, matrix 연산, conditional probability와 Bayes rule을 미리 복습하세요.
