# Cornell CS4780 지능형 시스템을 위한 머신러닝 - 한국어 번역 해설

원문: [Fall 2018 course](https://www.cs.cornell.edu/courses/cs4780/2018fa/) · [Lecture notes](https://www.cs.cornell.edu/courses/cs4780/2018fa/lectures/)

확인일: 2026-08-06

## 과정 목표

문제에 맞는 learning algorithm을 고르고 직접 구현하며, 평가하고 debug하는 능력을 기르는 입문 과정입니다.

## 확인 가능한 강의 흐름

1. 머신러닝 문제 설정
2. k-nearest neighbors와 차원의 저주
3. perceptron
4. data에서 확률 추정
5. Bayes classifier와 naive Bayes
6. logistic regression, MLE와 MAP
7. gradient descent
8. linear regression
9. support vector machine
10. empirical risk minimization
11. model selection
12. bias-variance tradeoff
13-14. kernel
15. Gaussian process
16. k-dimensional tree
17. decision tree
18. bagging
19. boosting
20. neural network
21. deep learning과 stochastic gradient descent

## 학습 포인트

강의 순서가 확률 추정과 linear model에서 시작해 tree ensemble과 deep learning으로 확장됩니다. 각 방법을 구현할 때 time complexity, memory, scaling 필요 여부와 hyperparameter에 대한 민감도를 함께 비교하세요.
